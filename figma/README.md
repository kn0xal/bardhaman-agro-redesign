# Bardhaman Agro Products — Figma handoff

`bardhaman-agro-redesign.svg` is an editable SVG concept board designed for import into Figma. Drag it into a new Figma file, then ungroup the imported layers to edit the cover, desktop homepage composition, and visual system.

## Included on the board

- Desktop homepage hero composition
- Product card direction
- Grain journey / process direction
- Palette and type scale
- Liquid-glass component examples

## Design system

- Ink: `#102C21`
- Paper: `#F4F0E5`
- Moss: `#E7EEE3`
- Signal lime: `#D7EF4A`
- Warm gold: `#E7B863`
- Display: Playfair Display
- UI: DM Sans
- Metadata: DM Mono

The working demo is the HTML prototype in the project root. Open `index.html` directly or serve the folder with any static file server.
