# Bardhaman Agro Products redesign demo

Presentation-ready frontend concept for the BAPPL website redesign.

## Run it

From this folder:

```bash
npx serve .
```

Then open the local URL shown by the command. `index.html` also opens directly in a browser, but a local server gives the cleanest demo experience.

## Demo route

- `index.html` — homepage / “grain to globe” story
- `about.html` — company story and timeline
- `products.html` — filterable product catalogue
- `product-detail.html` — product detail / trade enquiry view
- `process.html` — six-step manufacturing story
- `gallery.html` — facility and community gallery
- `news.html` — news and events
- `contact.html` — enquiry form demo

## Design handoff

Open `figma/bardhaman-agro-redesign.svg` in Figma by dragging it into a new file. It contains the visual direction board, a homepage composition, product-card treatment, palette and type pairing. `figma/README.md` documents the system.

The enquiry form is frontend-only and shows a confirmation state for the meeting demo. No backend or CRM submission is connected.
